# 🏢 WorkSphere — Employee Workspace Management

A visual and interactive web application for managing employees and assigning them to different areas of a workplace while respecting role-based access rules.

## 📌 Project Overview

WorkSphere is a workspace management application that allows users to visually organize employees on a building floor plan.

The application allows users to:

* Add and manage employees.
* Assign employees to different workplace zones.
* Move employees between zones.
* Remove employees from their assigned zone.
* View detailed employee profiles.
* Apply role-based access restrictions.
* Manage zone capacity limits.
* Search and filter employees.
* Save the workspace state using localStorage.
* Use the application on desktop, tablet, and mobile devices.

## 🎯 Main Objectives

* Create an intuitive and interactive employee management interface.
* Display a floor plan with different workplace zones.
* Implement role-based zone restrictions.
* Create an employee creation form with validation.
* Add dynamic professional experiences to employee profiles.
* Implement employee photo preview.
* Display detailed employee information.
* Manage employee assignments and zone capacity.
* Add responsive design for different screen sizes.
* Apply smooth CSS animations and transitions.
* Validate HTML and CSS using W3C standards.
* Organize the project using an Agile workflow.

## 🎓 Context

This project was completed at **YouCode** as part of a front-end development brief.

The objective was to simulate a real-world workplace management application where employees can be visually assigned to different areas of a building while respecting business rules related to their roles.

The project allowed me to practice **JavaScript interactions, form validation, dynamic content, role-based logic, responsive design, localStorage, and interactive UI development**.
